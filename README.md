# Tsavo Trails – Safari Website

## About the Project

**Tsavo Trails** is a safari and travel website project that we are developing as part of our journey into learning Web Design and Development.

We started building this website while learning HTML and CSS. Instead of waiting until we had completed the lessons, we decided to put what we learned into practice by gradually creating a real website.

As we learned how to structure an HTML document, we applied that knowledge to the project. When we moved on to CSS, we started styling the pages, improving layouts, adding backgrounds, and making the website more visually appealing.

This project is still under development, and we continue to improve it as we learn new concepts and techniques.

## Project Objectives

The main objectives of this project are to:

- Practise writing semantic HTML.
- Understand how to structure multi-page websites.
- Learn how to style web pages using CSS.
- Understand how to use external CSS stylesheets.
- Practise website layouts using Flexbox and CSS Grid.
- Learn how to create responsive designs for different screen sizes.
- Improve our problem-solving and practical web development skills.

## Technologies Used

The project currently uses:

- **HTML5** – For creating the structure and content of the website.
- **CSS3** – For styling, layouts, colours, typography, backgrounds and responsiveness.

More technologies and functionality may be introduced as we progress with our learning.

## What We Have Learned So Far

Through building this project, we have been practising:

- Creating the basic HTML document structure.
- Using HTML elements, headings, paragraphs and links.
- Working with semantic HTML elements such as `header`, `nav`, `main`, `section`, `article` and `footer`.
- Adding images to web pages.
- Creating navigation links between different pages.
- Connecting external CSS files to HTML documents.
- Styling text, backgrounds, borders and spacing.
- Using CSS selectors and properties.
- Working with Flexbox and CSS Grid.
- Applying media queries to improve responsiveness.
